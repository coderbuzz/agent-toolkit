# Product Interface Design

## Workflow

1. Confirm the audience, primary user job, platform, constraints, and approved
   requirements.
2. Audit existing design language and reusable components.
3. When direction is unresolved, propose distinct options with trade-offs and a
   recommendation.
4. Define hierarchy, layout, typography, color, spacing, interaction, and one
   purposeful signature element.
5. Design loading, empty, error, success, permission, and destructive states.
6. Write active, specific, user-centered interface copy.
7. Verify responsiveness, keyboard access, focus, contrast, semantics, motion,
   localization expansion, and reduced-motion behavior.
8. Implement only when the assigned role has workspace-write scope; otherwise
   produce a design specification.

## Boundaries

Avoid generic visual defaults, decorative data, inaccessible interactions, and
unapproved product behavior. Do not expose private reasoning transcripts.
